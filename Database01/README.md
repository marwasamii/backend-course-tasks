# Database 01

This folder contains tasks and assignments related to database fundamentals.

## Sessions Overview
- **Session 01:** ERD (Entity Relationship Diagram)  
  Focused on understanding entities, attributes, relationships, and cardinality.

- **Session 02:** Mapping  
  Focused on mapping ERD to relational schema (tables, primary keys, and foreign keys).

## Structure
- Each session has its own folder
- Each session contains the related assignments and exercises
